# Portfólio — Vinicius Silveira

Este repositório contém o código do meu **site de portfólio**, onde apresento meus projetos e disponibilizo um contato direto via WhatsApp.

## 🔗 Acesse
- **Site:** *http://devinicius.site/*
- **Repositório:** este projeto

## Seções do site
- **Início:** foto, nome e cargo/objetivo
- **Sobre mim:** apresentação breve e objetiva
- **Projetos:** cards com imagem, título e descrição
- **Contato:** formulário que envia mensagem diretamente para o WhatsApp

## Projetos em destaque
- **Site institucional — Clínica de Fisioterapia &amp; Pilates (projeto real)**  
  Site desenvolvido para apresentar serviços e facilitar o contato.

- **Landing Page — Loja Streetwear Urban Style (prática de curso)**  
  Projeto de estudo com foco em layout e identidade visual.

- **Página de Planos — Tabela de Hospedagem (Price Cards) (prática de curso)**  
  Projeto de estudo para treinar UI com cards e comparativo de planos.
